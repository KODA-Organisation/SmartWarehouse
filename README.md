# Smart Warehouse Project

Проект умного склада для Koło Naukowe w Politechnice Częstochowskiej

## Структура проекта
- **docs/** - Документация и бланки PCz
- **firmware/** - Код для роботов (C++)
- **algorithms/** - Алгоритмы навигации (C++)
- **server/** - Серверная часть и UI (C#)
- **shared/** - Общие форматы данных

How class look like:

class Timer{
    // Those are volatile variables, needed to make sure to get "true" values
    volatile long seconds;
    volatile bool shouldClose;

    // This basically is to get our destination of instance
    // we need this to proceed with task-controlling 
    TaskHandle_t taskHandle = nullptr;

    // We have to make it static, because FreeRTOS using C
    // store pointer to object
    static void TaskPoster(void* config);

    // ...
};

                //  get pointer to object
void Timer::TaskPoster(void* config){
    // When delivered converts onto "just pointer"
    // Thats why we need static cast, this pointer contains Timer instance
    Timer* instance = static_cast<Timer*>(config);
    // initiate function
    instance-> Run();
}

Now lets take a close look to Run and Start functions:

void Timer::Run(){
    while(!shouldClose){
        seconds++;
        vTaskDelay(pdMS_TO_TICKS(1000));
        // pdMS_TO_TICKS - macros converter 
        // pc doesnt understand "seconds" as human
        // it tooks ms and divides by duration of one tick 
    }
    // if something will cause end of cycle - task should terminate itself
    taskHandle = nullptr;
    vTaskDelete(NULL);
}

// This is C-like thingy
void Timer::Start(){
    // "Exception"
    if(taskHandle != nullptr) return;

    xTaskCreatePinnedToCore(
        TaskPoster, // what to do
        "Timer", // name
        2048,   // stack size
        this,   // object pointer
        1,      // Priority
        &taskHandle, // make freertos know how to access task
        1       // which core
    );
}

Hierarchy: Start -> Run
Start is parent and conspiculous Run child func
Needed to start off task
-------------------------------------------------------------------------------------------------->
Start() kicks the OS to spawn a task on Core 1 and exits immediately; 

TaskPoster() is a static C-compatible bridge that unpacks this via static_cast.

Run() is the actual worker loop on a private stack; 
it must self-terminate with vTaskDelete(NULL) if the cycle ever breaks to prevent a Kernel Panic.

KODA Robot Ecosystem (Core & Libraries)
1. KODA Robot Core (System Handler)
    Status: System-level core (Work in Progress).
Primary Objectives:
   - LEGO Technic Experience: 
        Designed to make robot programming feel like assembling a LEGO Technic set.
   - Unified System Integration: 
        Merges all separate hardware components into a single, cohesive unit.
   - Simplified Control: 
        Streamlines high-level robot management through a centralized interface.

2. Motor Control Library (TT DC Motor Specialist)
    Hardware Focus: Exclusively optimized for TT DC Motors at this stage.
Primary Objectives:
   - Granular Commands: 
        Provides basic control for individual motors, including movement, stopping, and variable speed.
   - SOLID & OOP Architecture: 
        Built on strict Object-Oriented Programming principles for clean and maintainable code.
   - RobotUtils Compatibility: 
        Enables the creation of Motor objects to be easily consumed and controlled within the main Robot class.

3. UltraSonic Sensor Library (USS)
    Status: Fully integrated with the Robot Core
Primary Objectives:
   - "Pain-Free" Distance Logic: 
        Automates the low-level process of triggering pulses, 
        timing echoes, and calculating the resulting math.
   - Clean Data Output: 
        Returns processed distance values instead of raw microseconds.
   - Hardware Abstraction: 
        Completely hides the complexity of sound wave physics; 
        the user simply requests the distance, and the library delivers.
   - Seamless Integration: 
        Designed to work within the Robot class for high-level logic, 
        such as automatic obstacle avoidance.
